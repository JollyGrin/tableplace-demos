tableplace demos

One folder per game. Each demo turns a game site's own deck data into a playable lobby with one POST — then you play board games online at table.place. View source — the code is the tutorial. API reference: api.table.place/llms.txt.

  • Ardent Reapers

    TIER A — live deck API, CORS open

    Paste two deck URLs from ardentreapers.com, get a two-seat duel lobby seeded with both decks.

  • Cataclysm Arcade

    TIER B — public API, CORS closed: snapshot + proxy

    Paste two the-cade.com pack or deck links, get a two-seat table with Bosses in play, counters and token piles.
